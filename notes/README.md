# Nhật ký học

Mỗi ngày một file `YYYY-MM-DD.md`, đúng 4 dòng:

```md
## 2026-11-03
- Làm: pipeline lint + test cho repo mẫu
- Hỏng: cache pip không hit vì cache-dependency-path sai
- Sửa: trỏ đúng requirements-dev.txt
- Hiểu ra: cache key phải gắn với file lock, không phải tên job
```

Mục đích: cuối tuần đọc lại 5 file là ôn được toàn bộ, và mỗi mục "hỏng → sửa" là một câu trả lời phỏng vấn có thật.
